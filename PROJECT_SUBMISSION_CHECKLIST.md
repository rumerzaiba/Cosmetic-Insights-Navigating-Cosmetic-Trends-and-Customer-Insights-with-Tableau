# Project Submission Checklist

Use this checklist to confirm the project meets the instructions shown in the rubric.

## 1. Data Collection & Extraction from Database

- Dataset is available in the repository
- Tableau is connected to the dataset
- Source data fields are documented in the data dictionary

## 2. Data Preparation

- Missing and inconsistent values are reviewed
- Duplicate rows are removed if needed
- Fields are standardized for Tableau usage
- Calculated fields are defined in the build guide

## 3. Data Visualizations

- At least 5 unique visualizations are planned
- Visuals cover market overview, brand performance, pricing, skin-type suitability, and consumer preference trends

## 4. Dashboard

- Dashboard layout is responsive
- Global filters are available
- Navigation between sheets is included

## 5. Story

- Story contains multiple scenes
- Story follows the project narrative from overview to insights

## 6. Performance Testing

- Dataset size supports testing
- Filters and calculated fields are reviewed
- Dashboard loading is checked

## 7. Web Integration

- Dashboard is published on GitHub Pages
- Live link is included in the README
- Repository link is ready for submission if required

## 8. Project Demonstration & Documentation

- README contains the direct live dashboard link
- Project report and executive summary are included
- Presentation notes and dashboard plan are included
- A walkthrough video can be recorded separately if required

## Suggested Deliverable Count

- Data preparation: completed
- Unique visualizations: 5
- Dashboard sheets: 5
- Story scenes: 3 to 5
- Calculated fields: 4
